# Demo GIF generator

`docs/demo.gif` is a rendered illustration, not a screen recording. Nothing here touches WeChat or `/Applications`.
The terminal text follows `skills/wechat-multifix/SKILL.md`; the Dock uses the real `black.png` preview (the original green icon is the same glyph tinted green).

Rebuild (needs Google Chrome, ffmpeg, optionally gifsicle):

```bash
python3 docs/demo/build.py
```
