# Contributing

Thanks for helping! Issues and pull requests are welcome.

1. Fork and clone the repo.
2. Make your change on a branch. Keep it small and focused.
3. Check it: `bash scripts/check-skill.sh`
4. Open a pull request and say what you tested and on which macOS version.
5. Never commit personal data: real names, account IDs, local paths, API keys, or screenshots of private content.

See [AGENTS.md](AGENTS.md) for the project layout and rules (humans and AI agents both use it).
